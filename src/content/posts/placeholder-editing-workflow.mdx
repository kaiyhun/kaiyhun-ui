## Images use the site pipeline

Posts embed photographs through the same `ResponsiveImage` + imagetools
flow as every gallery — LQIP blur-up, AVIF/WebP tiers, lazy loading:

  picture={demoShot}
  placeholder={demoLqip}

Plain markdown images work too, but the component form keeps the
performance budget intact.
